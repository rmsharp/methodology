P2 (ratchet-kept-output-plan.md section 6, DONE item 4): a mutation round on the 1.6.0 keeper code

Harness: mutate-p2.py (this directory). 51 mutants, each a one-place rewrite of a scratch copy of
starter-kit/quality_ratchet.py; the six new test classes then run with -f. Controls first: M00 changes nothing and
must SURVIVE (the classes pass on the unmutated copy); M01 stops run_gates calling the keeper and must be KILLED.
Both behaved, in both rounds. The four older load-sensitive classes are not run (they test code this round does not touch).

ROUND 1 (against the 52 tests of the six classes as committed in layer 0 and 1): 49 mutants besides the controls; 35 KILLED, 14 SURVIVED:
M12 (a stream of exactly the cap is cut), M26 (a made-safe name is not lowercased), M30 (a leading hyphen is not made
safe), M31 (a long plain-looking name is its own folder), M37 to M39 (a stored path may name any directory, need not
start with the directory, need not be a kept file's name), M40 (a stored path that is a link is printed), M41 (a gate
folder that is a link is counted), M42 (the on-disk line names the oldest across folders), M43 (a directory that is a
link is scanned), M44 (the start time is taken when the file is written, not before the first gate), M48 (same-second
files sort by name, not by their number), M50 (a failure to build the keeper is silent). None was equivalent: each is a
behaviour the plan states and no test named.

Each survivor was given a test (11 new tests; 4 existing tests widened: two more odd gate names, a lowercase-prefix
assertion). A finding on the way: a test of seven runs inside one second read red, because pruning frees the plain
name and the next run takes it back, so it sorts oldest. Runs take minutes, so more than five in one second is not a
real case; the test was replaced by one that plants four files of one second and then runs twice, which is the ordering
rule the mutant breaks.

ROUND 2 (the 14 survivors and the two controls, against the 63 tests of the six classes after the additions): all 14 KILLED.

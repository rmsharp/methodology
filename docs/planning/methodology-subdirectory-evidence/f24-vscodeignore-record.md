# F24 — the tool reads a root `.vscodeignore` as vsce reads it (BL-101, plan section 7.6, S299)

Register row F24 ([`findings-register.md`](findings-register.md)). At the S299 Phase 0 picker he chose F24 as the deliverable, with the description "`bin/migrate-layout` would evaluate a root `.vscodeignore` the way it already does `.Rbuildignore`, using vsce's matching rules". F10 is the precedent for the rest, so none of it was put to him as a question: the tool **lists and never edits, with no refusal and no new exit code**; a refusal is the alternative not built (section 5, item 7). For this change nothing was run in an adopter's real tree (the adopter work is in clones), nothing was pushed and nothing went upstream; the tool is canonical-only, so no adopter receives it until D8.

## 1. The problem

P17 moved `vscode_quarto_ext` and the tool's own checks read green while the project's `release-gate` (`npm run check-package`) read 78 files against 42: vsce matches each `.vscodeignore` line with no `matchBase`, so a bare name (`SESSION_RUNNER.md`) is the project root's and `methodology/SESSION_RUNNER.md` is packaged. F11 had filed the file as `config` and listed its 26 mentions; the tool could say the file names moved files and not what the move does to it ([`p17-vscode-quarto-ext-record.md`](p17-vscode-quarto-ext-record.md) section 3). Plan section 7.6: a finding the tool's checks did not see goes before the next adopter.

## 2. What vsce does (read, then run)

Read in `@vscode/vsce` 3.9.2, `out/package.js` `collectFiles` (lines 1269 to 1306; S290 read the same call in 3.6.0). The list is the file's lines, each split at `\n` or `\r`, trimmed, with empty lines and lines starting `#` dropped; a line whose last segment has no `*` also stands for `<line>/**` (`<line>**` when it ends in `/`), a negation too; vsce's own 32-entry `defaultIgnore` is added in front and `!package.json` and `!README.md` behind; a file is **kept when no ignore pattern matches it or any negation does, wherever the negation sits**. Every match is `minimatch(path, pattern, { dot: true })`. Run: a toy project with the one line `SESSION_RUNNER.md` lists `methodology/SESSION_RUNNER.md` and `methodology/.gitattributes` and not the root `SESSION_RUNNER.md` or `.gitattributes` (the second is on the default list, root only): **one of the 36 files P17 put into the `.vsix` was a file the sync itself created**.

## 3. The change (`bin/migrate-layout`)

- `vsce_glob(pattern)`: this tool's translation of minimatch's matching for the subset below, as a function (path) -> bool, or None for a pattern it does not read. A `**` segment matches any number of segments and, last, one or more (`a/**` is not `a`); `*` and `?` stop at `/` and reach a leading dot; a leading `/`, a `.` segment and a trailing `/` match nothing; case-sensitive; a pattern with no `/` is the root's. `{a,b}` lists (nested too), `[abc]`, `[a-c]`, `[!a]`, `[^a]` are read. **Not read, counted:** extended globs (`+(a|b)`), brace ranges (`{1..3}`), a lone `{a}`, a backslash, POSIX classes, `a//b`, an unclosed, empty or `]`-first class.
- `vsce_ignore_list(text)`: the list as vsce builds it (section 2); `covering(path)` gives the lines that ignore a path, none when a negation brings it back.
- `vscodeignore_exposure(text, mapping)`: a moved file is **exposed when it is ignored where it is and packaged where it goes**; the result has `pattern_exposure`'s shape (`exposed`, `lines`, `unread`), and vsce's default list is reported as line 0, after the file's own lines.
- `scan_hits` reads a tracked root `.vscodeignore` as it reads a root `.Rbuildignore`; the row it already has keeps its fields and gains `patterns`, and a file with no exposure gets no row it did not have. The text prints one line per exposing line, `vsce's default list: .gitattributes  stops covering .gitattributes` for line 0, then one sentence: how many lines cover how many moved files, that a line such as `methodology/**` would cover the new directory, the vsce and minimatch versions it was checked against, and that it is a candidate, not a verdict. Any other pattern list (`.npmignore`, `.vercelignore`) is still listed and never judged.
- Not changed: the move, the rewrites, the exit codes, `.Rbuildignore`, `bin/sync`, the manifest.

## 5. What the list cannot show

1. **It is this tool's translation of minimatch, not minimatch.** The agreement is measured on the subset above (section 4), for vsce 3.9.2 and minimatch 10.2.5; a pattern outside it is counted (`unread`) and plays no part, so a line that would cover the new directory but is not read leaves the exposure reported, and a line that covers a moved file but is not read leaves it missed. The text says how many lines were not read.
2. **Versions.** vsce's default list and matching are those of 3.9.2 (the same call in 3.6.0, read in S290); a vsce that changes either is not seen until the pin, the table and part C of the script are re-run.
3. **Only the root `.vscodeignore`.** vsce's `--ignoreFile`, an extension packaged from a subdirectory, and the `files` property of `package.json` (vsce uses it only when there is no `.vscodeignore`) are not read.
4. **The row counts the tool's map, not the disk** (F10's limit 6): the 38 in the dry run's sentence (`23 line(s) cover 38 moved file(s)`) includes `dashboard.html` and `.quality-gates-results.json`, which a clone does not have; vsce's count of 36 is the files that exist.
5. **A population of one.** Of the repositories on this machine only `vscode_quarto_ext` tracks a root `.vscodeignore`, and it is already moved; the rule is for the next VS Code extension that adopts the framework. `wsfct` tracks a `.vercelignore` and `nprcgenekeepr` a `.Rbuildignore` (F10); the first is **listed, never judged**: its dialect was not read here, and the next adopter that carries one is F24's second instance unless that is done first.
6. **Not shown:** an adopter that read the row and acted on it; `vsce package` run after the move with the new tool (the `vsce ls` listing is what `package` zips: P17 measured 44 entries and 1,935,373 B before and after for the fixed arm); the extension's own `check-package` (the scratchpad in the real tree makes it a 66 GB walk; the clones have none).
7. **A refusal was not built.** The move that exposes 36 files commits and the row says so; a refusal (exit 1 before any write, until a line covers `methodology/`) would make P17's order mandatory instead of listed. F10 listed, and this follows it; it is his to change.
